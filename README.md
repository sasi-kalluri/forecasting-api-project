# Sales Forecasting System

This project is an end-to-end time-series forecasting system built using:
- XGBoost
- ARIMA
- Prophet
- LSTM

The system predicts future sales using historical sales data and exposes predictions through a Flask REST API.

## Features
- Feature Engineering
- Multiple Model Comparison
- Best Model Selection
- REST API Deployment

## Best Model
XGBoost achieved the lowest MAE and was selected as the final model.
